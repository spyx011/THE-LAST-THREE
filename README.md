# THE-LAST-THREE

This is a RPG type game 

-->WASD / Arrow Keys — Move

-->E — Interact and trade

#Built With

    Godot Engine

    GDScript

#Gameplay

Explore the world and interact with characters.

Collect gold and trade resources.

Obtain meat, wood, and a seat through quests.

Assemble the boat and help the cowboy rescue the duck.
